# Agendamento SUS – Versão Web

Sistema web desenvolvido durante o Projeto Integrador do curso técnico em Informática para a Internet (IFES). Tem como objetivo facilitar o agendamento de consultas no SUS, com interface intuitiva e acessível para pacientes e painel de administração.

## 📌 Funcionalidades
- Cadastro e login de pacientes
- Escolha de especialidades e médicos
- Agendamento de consultas online
- Barra de Acessibilidade

## 💻 Tecnologias utilizadas
- HTML5, CSS3, JavaScript
- PHP (backend)
- MySQL (banco de dados)

## 🧱 Estrutura do sistema
- Frontend com páginas dinâmicas em PHP
- Backend com lógica de autenticação e validação
- Banco de dados relacional
